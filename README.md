## 🚀 How to Run

1. Clone this repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Open the project folder.
3. Compile a C program using GCC:
   ```bash
   gcc filename.c -o program
   ```
4. Run the program:
   ```bash
   ./program
   ```

   On Windows, use:
   ```bash
   program.exe
   ```
